# Bullseye — Gemini-assisted English coaching (Phase 6)

This is an **optional** narration layer. It does not change `app/api/video.py`, YOLO26, MediaPipe, ball tracking, or shot detection. It uses the Phase 6 evidence-enriched JSON already generated by Bullseye.

## Architecture / trust boundary

1. Existing Phase 5/6 vision pipeline supplies observed shooting data.
2. `ConciseEnglishVoice` validates timing, references, measurements, replay links, and no-grading restrictions; it derives at most **two** observed sentences per shot.
3. Optional Gemini (`--use-gemini`) chooses **only** an English presentation style and evidence ordering from an allowlist. The prompt sends **those short evidence sentences**, not the video.
4. `coaching_script_validator.py` rejects free-text narration, invented evidence IDs, dropped evidence, unsupported claims, duplicate IDs, and unauthorized styles.
5. Bullseye assembles final speech using only approved sentences and fixed introductions/review prompts; no invented correction or made/missed count is possible in this stage.
6. Existing `english_voice_sapi.ps1` speaks the final script locally as a WAV via Windows System.Speech. Without Gemini, with no key, after a quota error, or on an invalid response, the same local narration still works.

**Important:** This is Gemini-assisted editorial selection, *not* unconstrained Gemini-written technical diagnosis. It trades some stylistic flexibility for evidence safety. It does not yet identify actual mistakes, calculate intended body/hand placement, classify makes/misses, or calculate an ideal trajectory.

## Files and installation

Download the separate files into Windows Downloads, then from `D:\Bullseye\backend` in the active `.venv`:

```powershell
Copy-Item "$HOME\Downloads\coaching_script_validator.py" "app\coaching\" -Force
Copy-Item "$HOME\Downloads\gemini_coaching_writer.py" "app\coaching\" -Force
Copy-Item "$HOME\Downloads\coaching_audio_pipeline.py" "app\coaching\" -Force
Copy-Item "$HOME\Downloads\test_gemini_coaching.py" "tests\" -Force
Copy-Item "$HOME\Downloads\README_GEMINI_COACHING.md" "." -Force
```

Keep these **existing** dependencies in `app\coaching\`:
`english_voice.py`, `english_voice_sapi.ps1`, and `concise_english_voice.py`.

No new Python package is required: the optional Gemini client uses Python's standard library.

## Optional: turn on Gemini

1. Open https://aistudio.google.com/apikey and obtain a Gemini API key for a project with available quota. Confirm your plan's pricing/quota before use. A free tier is **not guaranteed** for every account or region; API usage can incur costs on a paid project.
2. Put the key in the **current PowerShell process only**:

```powershell
$secureKey = Read-Host "Gemini API key" -AsSecureString
$env:GEMINI_API_KEY = [System.Net.NetworkCredential]::new("", $secureKey).Password
Remove-Variable secureKey
```

Don't paste the key into chat, source code, README, or a tracked `.env` file.

3. To **test Gemini selection without generating WAV**, use a NEW output directory:

```powershell
python -m app.coaching.coaching_audio_pipeline `
  --input data/analyzed/phase6_evidence_feedback_video3.json `
  --output-dir data/analyzed/phase6_gemini_script_video3 `
  --use-gemini --script-only
```

Inspect:

```powershell
$g = Get-Content "data/analyzed/phase6_gemini_script_video3/voice_manifest.json" -Raw | ConvertFrom-Json
$g.shots | Select-Object shot_number,gemini_status,spoken_word_count,script_source
$g.shots[1].narration_text
```

Expected for Shot 1: `not_needed`; for Shot 2, `accepted` if the API responds validly, otherwise `invalid_or_unavailable` or `api_key_missing` with a safe local fallback.

4. Generate a real WAV using another NEW directory:

```powershell
python -m app.coaching.coaching_audio_pipeline `
  --input data/analyzed/phase6_evidence_feedback_video3.json `
  --output-dir data/analyzed/phase6_gemini_voice_video3 `
  --use-gemini
Invoke-Item "data\analyzed\phase6_gemini_voice_video3\shot_002_english_ai_voice.wav"
```

5. Delete the session variable when finished:

```powershell
Remove-Item Env:\GEMINI_API_KEY
```

## Data privacy and output controls

- The script only sends up to two approved short measurement sentences for a qualifying shot. It does **not** send the MP4, frames, name, video URL, coordinates, local filenames, or full medical/personal data.
- Google's API processes these sentences, and **free-tier requests may be used by Google to improve its products**. Read Google's terms/privacy policy before enabling requests.
- API error, outage, invalid JSON, and bad selected evidence IDs fall back safely to offline narration; fallback status is recorded in `voice_manifest.json`.
- Existing `corrections_generated=0`, `intended_form_match=not_assessed`, and made/missed `not_assessed` stay unchanged.
- English only. Output WAV uses your local Windows installed English voice, which may sound synthetic; Gemini is used for presentation, **not** as the TTS engine.
- The output folder is intentionally non-overwriting. Choose a fresh `--output-dir` on every run or back up your results.
